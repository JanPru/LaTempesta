\section{How to Add Multiple CSV Files}

To use multiple CSV files, modify \texttt{MapPage.jsx} to iterate through an array of CSV file paths, loading and parsing each one. Combine all the resulting features into a single GeoJSON FeatureCollection before setting the state. Each new CSV file must be placed in \texttt{frontend/public/} and must have the same column structure (or at least the required columns: \texttt{lat}, \texttt{lon}, \texttt{Country}, \texttt{Library Name}).

\section{URL Parameters}

The MapPage component reads URL parameters to initialize filters:

\begin{lstlisting}
// MapPage.jsx
const [searchParams] = useSearchParams();

// Sync filter from URL when searchParams change
useEffect(() => {
  const filterParam = searchParams.get("filter");
  if (filterParam && validFilters.includes(filterParam)) {
    setActiveBottomFilter(filterParam);
  }
}, [searchParams]);
\end{lstlisting}

Valid filter values: \texttt{library\_status}, \texttt{type\_connect}, \texttt{not\_connect}, \texttt{perceived\_quality}
